# Circle: Social Network Platform (MERN + Socket.IO)

Terminal 1:  cd server  ->  npm install  ->  npm run dev   (port 5000)
Terminal 2:  cd client  ->  npm install  ->  npm run dev   (port 5173)
Then open http://localhost:5173

Features: register/login, profiles with cover photo, posts with image/video, likes, comments,
save posts, share to friends, friend requests, real-time chat, 24-hour stories, videos page,
notifications, privacy settings, people suggestions.

Optional demo data:  cd server -> node seed.js   (remove it later with: node seed.js remove)
server/.env holds the database connection. Do not share or screenshot it.
